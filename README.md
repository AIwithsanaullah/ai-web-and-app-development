## Run locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Edit the project cards and contact links as your work evolves.

For local development, a simple static server is also suitable.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to provide the published URL.

## Security and quality principles

- Never commit API keys, access tokens, passwords, or client credentials.
- Keep secrets on the server side; do not put private keys in browser JavaScript.
- Use synthetic sample data in public demos.
- Make project status and limitations clear.
- Test mobile layouts, keyboard navigation, form feedback, and external links before release.
